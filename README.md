# PYTHON-LAB-EXPERIMENT-3
PYTHON PROGRAMMING LAB EXPERIMENT 3

## Aim

To write a Python program to demonstrate various string operations, such as finding the length of a string, changing the case, accessing characters, searching, slicing, replacing, checking substrings, concatenating strings, and removing white spaces.

## Algorithm

1.Start the program.

2.Initialize a string s with the value "hello world".

3.Display the original string.

4.Find and display the length of the string using len().

5.Convert the string to uppercase using upper() and display it.

6.Convert the string to lowercase using lower() and display it.

7.Access and display the character at index 6.

8.Find the position of "world" using find() and display the result.

9.Perform string slicing from index 6 to the end and display it.

10.Replace "hello" with "python" using replace() and display the result.

11.Check whether "python" is present in the string using the in operator.

12.Concatenate another string with s using the + operator.

13.Initialize another string s1 containing extra white spaces.

14.Remove the leading and trailing white spaces using strip().

15.Display the resulting string.

16.Stop the program.
